# Citing Spectypus

Use this reference, replacing X with the version used in your analysis:

> Spectypus: supernova spectral classification software. GitHub:
> https://github.com/doctorbrew/spectypus (Version X).

Find the version with `spectypus --version`. For older runs, use their recorded version.

Example wording for a paper using both classifiers:

> We used [Spectypus](https://github.com/doctorbrew/spectypus) (Version X)
> to run SNID-SAGE ([Stoppa & Smartt 2026](https://doi.org/10.1093/mnras/stag1066)),
> based on SNID ([Blondin & Tonry 2007](https://doi.org/10.1086/520494)), and
> NGSF ([Goldwasser et al. 2022](https://www.wis-tns.org/node/138742)), based on
> Superfit ([Howell et al. 2005](https://doi.org/10.1086/497119)), and to review
> their spectral matches for each supernova.

Adapt the sentence to the classifiers used and replace X with the version.

Copy entries from [references.bib](references.bib), and cite the sources of
the observed spectra and template collections used in your analysis.
